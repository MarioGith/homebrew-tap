# homebrew-tap

Homebrew tap for itsemi tools.

## Install

```bash
brew tap MarioGith/tap
```

## Available Casks

| Cask | Description |
|------|-------------|
| `claude-usage` | macOS menu bar app to monitor Claude Code usage limits in real-time |

### claude-usage

```bash
brew install MarioGith/tap/claude-usage
```

See the [ClaudeUsage repo](https://github.com/MarioGith/ClaudeUsage) for details.
