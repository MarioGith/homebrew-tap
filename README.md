# homebrew-tap

Homebrew tap for itsemi tools.

## Install

```bash
brew tap MarioGith/tap
```

## Available Casks

| Cask | Description |
|------|-------------|
| `cozy-fireplace` | Ambient fireplace video player with Pomodoro timer |

### cozy-fireplace

```bash
brew install MarioGith/tap/cozy-fireplace
```

See the [CozyFireplace repo](https://github.com/MarioGith/CozyFireplace) for details.
