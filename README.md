# homebrew-tap

Homebrew tap for itsemi tools.

## Install

```bash
brew tap MarioGith/tap
```

## Available Casks

| Cask | Description |
|------|-------------|
| `claude-usage` | macOS menu bar app to monitor Claude Code usage limits in real-time |
| `cozy-fireplace` | Ambient fireplace video player with Pomodoro timer |

### claude-usage

```bash
brew install MarioGith/tap/claude-usage
```

See the [ClaudeUsage repo](https://github.com/MarioGith/ClaudeUsage) for details.

### cozy-fireplace

```bash
brew install MarioGith/tap/cozy-fireplace
```

See the [CozyFireplace repo](https://github.com/MarioGith/CozyFireplace) for details.
